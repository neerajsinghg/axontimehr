# Security Policy — AxonTimeHR

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 14.0.x  | :white_check_mark: |
| < 14.0  | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities directly to `security@axontimehr.com`.
Do not disclose vulnerabilities in public GitHub issues.
